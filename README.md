# 3-Python-Web-Scraping-Projects-Ebook

## Example code from PipelineToDE ebook 3 Python Web Scraping Projects You Can Do In A Weekend

### Demystify, Simplify and Crush Python Web Scraping In 1 Weekend

In a data world oversaturated with messy CSVs and endless JSONs, web data represents a rich opportunity for analysis and discovery.

The problem? It can be intimidating for Python beginners.

Most online tutorials focus on extensive scrolling through and parsing of HTML tags. Instead, this guide introduces a simplified framework for ingesting data from 3 types of web data sources:

* Existing Tables Embedded In Websites
* Raw HTML (Using Python's Requests Library)
* Multi-Table Scraping Using Dynamic URLs

Web scraping doesn't have to be scary and once you explore the data sources included in this guide, you may even learn something new!
